## Mô tả các thành phần và quan hệ trong ảnh

Bảng chú giải ở góc trên bên trái phân loại 4 loại quan hệ (Edges) kèm màu sắc và số lượng quan hệ:

| Quan hệ | Màu sắc | Số lượng | Chi tiết quan hệ trong đồ thị |
| :--- | :--- | :---: | :--- |
| **`depts`** | Nâu (Brown) | 3 | • `User0 -> Dept1`<br>• `User1 -> Dept1`<br>• `User2 -> Dept0` |
| **`dept`** | Đỏ (Red) | 3 | • `Doc0 -> Dept1`<br>• `Doc1 -> Dept1`<br>• `Doc2 -> Dept1` |
| **`owner`** | Cam (Orange) | 3 | • `Doc0 -> User1`<br>• `Doc1 -> User1`<br>• `Doc2 -> User2` |
| **`reads`** | Xanh lá (Green) | 4 | • `User0 -> Doc1`<br>• `User1 -> Doc0`<br>• `User1 -> Doc2`<br>• `User2 -> Doc2` |

### Chi tiết các thực thể (Nodes/Atoms)
- **Phòng ban (`Dept`)**: Gồm 2 phòng ban `Dept0`, `Dept1` ($\le 3$).
- **Người dùng (`User`)**: Gồm 3 người dùng `User0`, `User1`, `User2` ($\le 3$).
  - `User0`: Thuộc `Dept1`, đọc `Doc1`.
  - `User1`: Thuộc `Dept1`, sở hữu `Doc0` & `Doc1`, đọc `Doc0` & `Doc2`.
  - `User2 ($crossRead_u)`: Thuộc `Dept0`, sở hữu `Doc2`, đọc `Doc2`.
- **Tài liệu (`Doc`)**: Gồm 3 tài liệu `Doc0`, `Doc1`, `Doc2` ($\le 3$).
  - Cả 3 tài liệu đều thuộc về `Dept1`.
